---
name: Railway pnpm lockfiles
description: Keeping Railway Railpack frozen installs compatible with workspace pnpm metadata
---

Railway Railpack may choose pnpm 9.x for a workspace whose lockfile was generated by a newer pnpm. If it reports `ERR_PNPM_LOCKFILE_CONFIG_MISMATCH`, regenerate the lockfile with the exact pnpm version Railway uses, then verify the same `--frozen-lockfile` install locally.

**Why:** pnpm major versions can serialize workspace settings such as overrides differently even when local installs succeed.

**How to apply:** Read the Railway log for its selected pnpm version, run lockfile-only regeneration with that version, test a frozen install, and commit only the resulting lockfile change.
