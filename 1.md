# Live Control Room — आसान समझ

## यह ऐप क्या करता है

यह local live-stream control room है। इसका काम है:

- पूरा Live URL और उसकी video category save करना
- किसी video category/group को channel से जोड़ना
- Channel को start, stop और delete करना
- Video categories बनाना और delete करना
- Category खोलकर उसके अंदर की videos देखना
- Video library में videos add और delete करना
- Dashboard पर live channels, viewers, videos और activity देखना

## Login

- Name या email में कोई भी नाम डालें
- Password: `dev`
- यह local demo login है। अभी production authentication नहीं है।

## Live channel जोड़ने का तरीका

1. `Live channels` में जाएं।
2. `Add channel` दबाएं।
3. केवल ये तीन चीजें भरें:
   - Live URL — पूरा URL सीधे paste करें, जैसे `https://a.upload.youtube.com/http_upload_hls?...&file=`
   - Video category — जिस category की videos चलानी हैं
4. `Add channel` दबाएं।
5. Platform अपने-आप Live URL से पहचान लिया जाता है; अलग Stream key भरने की जरूरत नहीं है।
6. Channel list में `Start` दबाने पर channel इस local control room में live दिखेगा।
7. `Stop` दबाने पर channel बंद/stopped दिखेगा।
8. जरूरत होने पर channel delete किया जा सकता है।

Live URL browser के local storage में रखी जाती है। इसे public chat में share न करें।

## Video categories

Video library में पहले categories दिखाई जाती हैं।

- Video library खुलने पर पहले categories दिखाई देती हैं।
- Category पर click करने से उस category के अंदर की videos खुलती हैं।
- Category delete की जा सकती है।
- Category खोलकर `Add video` से video file सीधे upload कर सकते हैं।
- किसी video को delete किया जा सकता है।
- Video title, चुनी हुई category और duration रखे जा सकते हैं।
- किसी video को चलाने के लिए channel में वही category select करनी है।

## असली streaming के बारे में जरूरी बात

`Start` button अब backend में FFmpeg process शुरू करता है:

- YouTube HLS URL (`http_upload_hls`) हो तो video HLS segments के रूप में YouTube को PUT होते हैं।
- RTMP या RTMPS URL हो तो video FLV stream के रूप में भेजी जाती है।
- अभी real server-side source के रूप में attached GTA video तैयार है।
- `Stop` FFmpeg process बंद करता है और process status control room में monitor होता है।

YouTube का पूरा ingest URL private रखें। अगर किसी नई browser-uploaded video को real stream में चलाना है, तो उसे server-side upload/storage flow में भी जोड़ना होगा; browser-only temporary file server को दिखाई नहीं देती।

## यह real streaming कैसे काम करती है

1. Live channel में डाला गया पूरा Live URL frontend से backend API को भेजा जाता है।
2. Backend channel की category को check करके server पर उपलब्ध video file चुनता है। अभी `GTA` category attached GTA MP4 file से जुड़ी है।
3. Backend `ffmpeg` को `-re` और loop mode में चलाता है, ताकि video live speed पर लगातार चलता रहे।
4. YouTube HLS URL होने पर FFmpeg video को छोटे MPEG-TS segments और playlist में बनाकर हर file को URL के `file=` parameter के साथ HTTP `PUT` करता है।
5. RTMP/RTMPS URL होने पर FFmpeg सीधे FLV stream भेजता है।
6. Start के बाद control room process status पूछता रहता है। FFmpeg बंद या fail होने पर channel अपने-आप live नहीं दिखता।
7. Stop दबाने पर backend FFmpeg process को बंद कर देता है।

इससे `Start` केवल local status बदलने के बजाय सच में server-side encoder process चलाता है। YouTube पर final broadcast तभी दिखाई देगा जब पूरा ingest URL सही हो और YouTube stream ready/active हो।
