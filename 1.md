# Live Control Room — आसान समझ

## यह ऐप क्या करता है

यह local live-stream control room है। इसका काम है:

- पूरा Live URL और उसकी video category save करना
- किसी video category/group को channel से जोड़ना
- Channel को start, stop और delete करना
- Video categories बनाना और delete करना
- Category खोलकर उसके अंदर की videos देखना
- Video library में videos add और delete करना
- Dashboard पर live channels, viewers, videos और activity देखना

## Login

- Name या email में कोई भी नाम डालें
- Password: `dev`
- यह local demo login है। अभी production authentication नहीं है।

## Live channel जोड़ने का तरीका

1. `Live channels` में जाएं।
2. `Add channel` दबाएं।
3. केवल ये तीन चीजें भरें:
   - Live URL — पूरा URL सीधे paste करें, जैसे `https://a.upload.youtube.com/http_upload_hls?...&file=`
   - Video category — जिस category की videos चलानी हैं
4. `Add channel` दबाएं।
5. Platform अपने-आप Live URL से पहचान लिया जाता है; अलग Stream key भरने की जरूरत नहीं है।
6. Channel list में `Start` दबाने पर channel इस local control room में live दिखेगा।
7. `Stop` दबाने पर channel बंद/stopped दिखेगा।
8. जरूरत होने पर channel delete किया जा सकता है।

Live URL browser के local storage में रखी जाती है। इसे public chat में share न करें।

## Video categories

Video library में पहले categories दिखाई जाती हैं।

- Video library खुलने पर पहले categories दिखाई देती हैं।
- Category पर click करने से उस category के अंदर की videos खुलती हैं।
- Category delete की जा सकती है।
- Category खोलकर `Add video` से video file सीधे upload कर सकते हैं।
- किसी video को delete किया जा सकता है।
- Video title, चुनी हुई category और duration रखे जा सकते हैं।
- किसी video को चलाने के लिए channel में वही category select करनी है।

## Data कहाँ save होता है

अभी यह पूरा version browser के `localStorage` पर चलता है। इसलिए:

- Refresh करने के बाद data बचा रहता है
- अलग browser या अलग device पर data अपने-आप नहीं आएगा
- Database या multi-user sync अभी नहीं जोड़ा गया है

## असली streaming के बारे में जरूरी बात

अभी `Start` button local dashboard में channel को live status देता है। यह version अपने-आप YouTube पर video publish करने वाला FFmpeg/RTMP engine नहीं चलाता। इसलिए Stream key save और local control-room testing के लिए तैयार है, लेकिन असली YouTube/RTMP broadcast के लिए encoder या backend streaming service अभी अलग से जोड़नी होगी।
